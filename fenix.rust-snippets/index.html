Install

  1. In Fenix, press SPC h x to open the Extensions page.
  2. Search for Rust snippets, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.rust-snippets-1.0.0.fenixext.

What it may do

Nothing: it's data (themes, snippets, keymaps, templates) and runs no code.

About

Snippets for the Rust you write every day. Type the key and press Tab; Tab moves between the fields, and the snippet ends where `` is.

KeyWhat
fnA function
pfnA public function
testA #[test] function
tmodA #[cfg(test)] module with use super::*;
implAn impl block
impltA trait impl for a type
stA struct, with #[derive(Debug, Clone)]
enAn enum, with #[derive(Debug, Clone, Copy, PartialEq, Eq)]
matchA match with two arms
ifletAn if let
letelseA let ... else
dispA Display impl

Your own snippet with the same key wins over these.
