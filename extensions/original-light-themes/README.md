# Original light themes

Fenix's light themes keep every colour at a contrast it can read: body
text and comments at 4.5:1 on each surface they're drawn on, accents at
3:1. Where a palette's own colour falls short, Fenix's copy darkens it.

This extension adds each of them as its authors published it, untouched,
named "… (original)":

- GitHub Light (original)
- One Light (original)
- Solarized Light (original)
- Gruvbox Light (original)
- Rosé Pine Dawn (original)
- Tokyo Night Day (original)
- Visual Studio Light (original)
- Catppuccin Latte (original)

Pick one with `SPC t p`.
