# Review

Code review on GitHub and GitLab: the reviews waiting, a request with
its threads and checks, and a new one for the branch. One install on the
welcome (`SPC h w`) or the Extensions page's Bundles (`SPC h x`) brings
them all.

| Extension | What |
|---|---|
| `fenix.review` | Code review on GitHub and GitLab |

Removing the bundle removes them too, unless you installed one on its
own or another extension needs it.
