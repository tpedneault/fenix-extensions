# Changelog

## 1.2.0

- The hints that named a leader sequence (`SPC m s`, `SPC m T`) say the keys
  the key scheme in use has: `C-k m s` with standard keys, your own leader
  chord if you set one, a key you bound yourself. Fenix doesn't say the keys of
  a `SPC m` menu entry, so these are written from the leader and the entry's
  key.

## 1.1.0

- For Fenix 1.5 (extension API 1.5): what it says names the keys of the
  key scheme in use -- `F12` for go to definition with standard keys,
  `gd` with Vim keys. The README gives standard keys beside Vim's.

## 1.0.0

- The first release, for Fenix 1.0: tcl scripts: Tcl's own usage lines on K, completion of options, subcommands, built-ins and your procs, go to definition, and the project's definitions by name.
