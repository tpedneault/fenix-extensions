# Changelog

## 1.1.0

For Fenix 1.5 and later: an older Fenix keeps 1.0.0, without Kubernetes,
which has no release for it.

- Kubernetes (`fenix.kubernetes`) joins the bundle: workloads, pods,
  services and logs through kubectl, a shell in a pod, port-forwards,
  and changes asked about first.

## 1.0.0

- The first release, for Fenix 1.0: arduino, containers, VNC.
