# Changelog

## 1.1.0

- For Fenix 1.5 (extension API 1.5): what it says names the keys of the
  key scheme in use, and yours where you rebound them -- a file with no
  schema says `C-k x V` picks one with standard keys, `SPC x V` with Vim
  keys.

## 1.0.0

- The first release, for Fenix 1.0: jSON, YAML and TOML: format with the project's indent, minify, sort keys, convert between them, query with JSONPath or jq, check against a JSON Schema (SchemaStore's by the file's name), escape strings, copy a key's path, and types from a sample.
