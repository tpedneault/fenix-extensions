# Changelog

## 1.1.0

- For Fenix 1.5 (extension API 1.5): the foot of the page says the keys
  that open the gallery from anywhere, as the key scheme in use has them
  -- `SPC h g` with Vim keys, `C-k h g` with standard keys, or yours when
  you've bound your own -- and says them again when you switch. With no
  key bound to it, it says nothing. The README gives standard keys
  beside Vim's.

## 1.0.0

- The first release, for Fenix 1.0: every `ui-kit` widget working on one page -- a table of 400 rows sorted and selected, a tree with a folder read only when it's opened, tabs, a text field and a `/` filter, a list with its empty state, a popup menu, splits, a scrolled region, the theme's roles, tints and palette, and the mouse -- each with the code that draws it a key away (`c`), for people writing extensions.
