# Changelog

## 1.1.0

- For Fenix 1.5 (extension API 1.5): built against API 1.5, as the shared
  `ui-kit` it draws its table with now is. The table works as it did; on
  Fenix 1.0 to 1.4, 1.0.0 stays the one you have.

## 1.0.0

- The first release, for Fenix 1.0: cSV and TSV files as a table: columns lined up, sorted and filtered, cells, rows and columns changed through the file's buffer, column stats, copies as CSV or Markdown -- a million rows as fast as ten.
