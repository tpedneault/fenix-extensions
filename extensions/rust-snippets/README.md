# Rust snippets

Snippets for the Rust you write every day. Type the key and press Tab;
Tab moves between the fields, and the snippet ends where `` is.

| Key | What |
|---|---|
| `fn` | A function |
| `pfn` | A public function |
| `test` | A `#[test]` function |
| `tmod` | A `#[cfg(test)]` module with `use super::*;` |
| `impl` | An `impl` block |
| `implt` | A trait `impl` for a type |
| `st` | A struct, with `#[derive(Debug, Clone)]` |
| `en` | An enum, with `#[derive(Debug, Clone, Copy, PartialEq, Eq)]` |
| `match` | A `match` with two arms |
| `iflet` | An `if let` |
| `letelse` | A `let ... else` |
| `disp` | A `Display` impl |

Your own snippet with the same key wins over these.
