# Changelog

## 1.0.0

- The first release, for Fenix 1.6 (extension API 1.5): a folder with a `kiln.toml` is a Kiln project (`KILN`), with `Kiln: open the plan` and `Kiln: read the project again`, the settings `kiln.path` and `kiln.refresh_seconds`, and an `SPC m` menu. The plan's pages are not in yet.
