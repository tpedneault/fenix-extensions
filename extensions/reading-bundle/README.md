# Reading

PDFs read in a pane, with an outline, search, marks and a shelf of what
you read. One install on the welcome (`SPC h w`) or the Extensions
page's Bundles (`SPC h x`) brings them all.

| Extension | What |
|---|---|
| `fenix.pdf` | PDFs read in a pane |

Removing the bundle removes them too, unless you installed one on its
own or another extension needs it.
