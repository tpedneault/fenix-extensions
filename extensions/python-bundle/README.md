# Python

Python in Fenix, for scripts, projects and notebooks: one install on the
Extensions page's Bundles (`SPC h x`), or the welcome's Python pack,
brings them all.

| Extension | What |
|---|---|
| `fenix.python` | basedpyright with ruff's server beside it, debugging with debugpy, ruff as the formatter, tasks, the project's checks with their fixes, outdated and vulnerable packages for uv and pip, snippets, and Django and Flask projects |
| `fenix.jupyter` | Jupyter notebooks (`.ipynb`): cells and their outputs, plots included, edited beside and run on the project's Python -- ipykernel when it's there, Python itself when it isn't |
| `fenix.csv` | CSV and TSV files as a table, for the data a notebook reads and writes |

Each one's README says the rest. Removing the bundle removes them too,
unless you installed one on its own or another extension needs it.
