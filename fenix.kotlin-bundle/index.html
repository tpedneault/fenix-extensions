Install

  1. In Fenix, press SPC h x to open the Extensions page, and its Bundles tab.
  2. Search for Kotlin, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.kotlin-bundle-1.0.0.fenixext.

What it may do

Nothing of its own: a bundle runs no code. Each extension it installs asks for its own permissions, below, and Fenix shows them before installing.

What it installs

  • Java and Kotlin fenix.java ^1

    Java and Kotlin: Eclipse JDT LS, debugging with java-debug, kotlin-language-server and Kotlin's highlighting, google-java-format and ktlint, Gradle's and Maven's tasks, the project's checks with their fixes, outdated and vulnerable dependencies, snippets, and Gradle, Spring Boot and Maven projects

    May use: runs programs, web requests, network connections, project files, the editor

About

Kotlin in Fenix. It lives in the Java and Kotlin pack, which shares the JVM, Gradle and the project doctor between the two; this bundle is that pack under Kotlin's name. One install on the Extensions page's Bundles (SPC h x) brings it.

ExtensionWhat
fenix.javaKotlin's highlighting, folds and indents (tree-sitter-kotlin); JetBrains' kotlin-lsp when it's installed, else kotlin-language-server, which the doctor installs; ktlint formatting and linting on save; Gradle's tasks; Kotlin snippets; Gradle application and library projects in the Kotlin DSL. Java too: JDT LS, java-debug, google-java-format, Maven

fenix.java's README says the rest. Removing the bundle removes it too, unless you installed it on its own or another extension needs it.
