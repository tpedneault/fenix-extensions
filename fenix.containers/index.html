Install

  1. In Fenix, press SPC h x to open the Extensions page.
  2. Search for Containers, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.containers-1.0.0.fenixext.

What it may do

Fenix holds it to these, and shows them before installing it. Everything else is closed to it.

Runs these programs on your computer
  • docker
  • podman
  • wslc
Reads the files in your project

About

Docker, Podman and wslc in Fenix: containers grouped by Compose stack, the project's own compose.yaml, live logs merged across a stack, performance, images and their layers, volumes and networks.

SPC d d opens it. SPC d p opens performance, SPC d b builds the project's Dockerfile.

A log page follows (F), shows times (t), filters (/), hides a stream (1-9) and opens as a buffer (o).

Engines

The first engine that runs is used: Docker, then Podman, then wslc. containers.engine pins one. An engine that's installed but not running says so, and Enter starts it (Docker Desktop, or Podman's machine).

wslc (WSL 2.9.3 or later, a preview) has containers and images, but no Compose, volumes or networks yet; those tabs say so.

Permissions

It runs docker, podman and wslc, and reads the project for its compose.yaml. It sends nothing anywhere.

Building it

cargo xtask pack extensions/containers dist

It needs Rust's wasm32-wasip2 target (rustup target add wasm32-wasip2).
