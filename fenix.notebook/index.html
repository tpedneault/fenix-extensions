Install

  1. In Fenix, press SPC h x to open the Extensions page.
  2. Search for Notebook, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.notebook-1.1.0.fenixext.

About

Notes, a daily journal, diagrams, links between them and quick captures, kept for you as plain files in one folder -- so making one never means choosing where it goes. Its keys are under SPC n.

The folder is notebook.folder, or the notebook folder in Fenix's data folder without one, read in place: notes/*.md, journal/YYYY/YYYY-MM-DD.md, diagrams/*.mmd, and index.toml beside them for names, pins and exports. Point it at a synced folder or an Obsidian vault and it works as it is.

Notes save themselves a second after you stop typing, and the version before each editing session is kept (h on the notebook page).

KeyWhat it does
SPC n nThe notebook page
SPC n N, SPC n dA new note from a template, a new diagram
SPC n jToday's journal day: the agenda's due tasks and yesterday's open checkboxes
SPC n cCapture a line into today's journal (> first: the Inbox; [ ] first: a task)
SPC n f, SPC n /, SPC n #Find by name, search (tag:, type:, project:, is:todo), tags
SPC n bWhat links here, beside the note
SPC n l, SPC n yInsert a link; copy a link to the line you're on
SPC n tThe checkbox under the cursor to the agenda
SPC n e, SPC n s, SPC n iExport; save a ```mermaid block as a diagram; import a file
SPC n v, SPC i DPaste a picture; insert a diagram
SPC m a, SPC m gIn a journal day: refresh its agenda list, add the day's commits

In Markdown, [[ completes a note's name and gd on a link follows it (making the note when it isn't there yet) -- with standard keys, F12 or Ctrl+click. The SPC keys above are Ctrl+K with standard keys.

With other extensions

  • Diagrams draws the diagrams in the page and exports (diagrams.*); SPC n d asks it for the kind and the starter.

  • Agenda fills a journal day's agenda list (agenda.due), takes SPC n t (agenda.add_task), and opens a [[FSW-212]] link (agenda.open_task).

Outside Fenix

The control channel's fenix/notebook.capture is answered by this extension. Fenix's reading view (SPC m p) asks it what [[links]] go to (notebook.link, notebook.follow).
