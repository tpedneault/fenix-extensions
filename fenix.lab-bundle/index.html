Install

  1. In Fenix, press SPC h x to open the Extensions page, and its Bundles tab.
  2. Search for Lab, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.lab-bundle-1.0.0.fenixext.

What it may do

Nothing of its own: a bundle runs no code. Each extension it installs asks for its own permissions, below, and Fenix shows them before installing.

What it installs

  • Arduino fenix.arduino ^1

    Arduino sketches: build, upload, the serial monitor, debugging, boards, ports, libraries, and the right language server

    May use: runs programs, project files

  • Containers fenix.containers ^1

    Docker, Podman and wslc: containers, Compose, live logs, performance, images, volumes and networks

    May use: runs programs, project files

  • VNC fenix.vnc ^1

    Remote desktops in a pane: the VNC (RFB) machines you list, each kept connected while Fenix runs

    May use: network connections, folders of yours, the clipboard

About

The bench: Arduino sketches, Docker and Podman containers, and the remote desktops you list. One install on the welcome (SPC h w) or the Extensions page's Bundles (SPC h x) brings them all.

ExtensionWhat
fenix.containersDocker, Podman and wslc
fenix.arduinoArduino sketches: build, upload, the serial monitor

Removing the bundle removes them too, unless you installed one on its own or another extension needs it.
