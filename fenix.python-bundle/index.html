Install

  1. In Fenix, press SPC h x to open the Extensions page, and its Bundles tab.
  2. Search for Python, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.python-bundle-1.0.0.fenixext.

What it may do

Nothing of its own: a bundle runs no code. Each extension it installs asks for its own permissions, below, and Fenix shows them before installing.

What it installs

  • CSV table fenix.csv ^1

    CSV and TSV files as a table: columns lined up, sorted and filtered, cells, rows and columns changed through the file's buffer, column stats, copies as CSV or Markdown -- a million rows as fast as ten

    May use: project files, the editor

  • Jupyter notebooks fenix.jupyter ^1

    Jupyter notebooks (.ipynb): cells and their outputs on a page -- code highlighted, markdown as it reads, tracebacks, matplotlib's plots and other pictures -- cells edited beside it and changed through the file's buffer, and run on the notebook's Python: ipykernel when it's there, Python itself when it isn't, input() asked of you

    May use: runs programs, project files, the editor

  • Python fenix.python ^1

    Python: basedpyright with ruff's server beside it, debugging with debugpy (the project's scripts, pytest, Django, Flask, FastAPI, attaching to a process), ruff as the formatter, tasks, the project's checks with their fixes, outdated and vulnerable packages for uv and pip, snippets, and Django and Flask projects

    May use: runs programs, project files, the editor

About

Python in Fenix, for scripts, projects and notebooks: one install on the Extensions page's Bundles (SPC h x), or the welcome's Python pack, brings them all.

ExtensionWhat
fenix.pythonbasedpyright with ruff's server beside it, debugging with debugpy, ruff as the formatter, tasks, the project's checks with their fixes, outdated and vulnerable packages for uv and pip, snippets, and Django and Flask projects
fenix.jupyterJupyter notebooks (.ipynb): cells and their outputs, plots included, edited beside and run on the project's Python -- ipykernel when it's there, Python itself when it isn't
fenix.csvCSV and TSV files as a table, for the data a notebook reads and writes

Each one's README says the rest. Removing the bundle removes them too, unless you installed one on its own or another extension needs it.
