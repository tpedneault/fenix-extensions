# {{name}}

Snippets for everyday editing. Type the key and press Tab; Tab moves
between the fields, and the snippet ends where `$0` is.

| Key | What |
|---|---|
| `todo` | A `TODO(name):` note |
| `fixme` | A `FIXME(name):` note |

They work in every language: their `# scope:` is `*`. A snippet for one
language says it instead (`# scope: rust`) and goes in a folder of that
name, `snippets/rust/`. Your own snippet with the same key wins over
these.
