## The colours

| | |
|---|---|
| Background | `#fbf9f4` |
| Text | `#2e2c29` |
| Keywords | `#8a3b8f` |
| Strings | `#2d7338` |
| Functions | `#2a5fa8` |

Body text and comments keep a contrast of 4.5:1 on each surface they're
drawn on, and accents 3:1.

## What it may do

Nothing. It's data alone: one theme file, no code, and it asks for no
permissions.
