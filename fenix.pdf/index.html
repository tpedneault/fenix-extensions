Install

  1. In Fenix, press SPC h x to open the Extensions page.
  2. Search for PDF reader, and install it. Fenix shows what it may do before it installs anything.

Or download the package and run fenix --install-extension fenix.pdf-1.1.0.fenixext.

What it may do

Fenix holds it to these, and shows them before installing it. Everything else is closed to it.

Runs these programs on your computer
  • fenix-pdfium
Sees where you are in the editor – the file, the cursor, the selection – when its commands run

About

PDFs read in a pane. A .pdf opens in it however you open it -- the explorer, the file picker, :e, a recent file, the command line, gf (with standard keys, Ctrl+click or Alt+F12) on spec.pdf#page=38 -- on a surface in the pane you're in: every page one under the other, fitted to the pane's width the first time, and where you left it after that.

The pages are rendered by fenix-pdfium, a small program that comes with Fenix, beside fenix.exe, with the PDFium library it uses. If you built Fenix yourself, docs/BUILDING.md says where to put it. PDFium isn't compiled to WebAssembly (docs/adr/0001-wasm-runtime.md), so the extension sends it requests over a pipe and draws what comes back: only the parts of pages in sight, and only the strip that scrolled into view as you read on.

SPC m on a PDF has them too. pdf.documents may run from outside Fenix (fenix/runCommand). The modeline says where you are: PDF p. 38/212 Fit width /packet 2/5. Home's reading lists the PDFs read lately, with the page you were on. With standard keys, SPC is Ctrl+K: Ctrl+K r f, Ctrl+K m.

It needs Fenix 1.5 or later (extension API 1.5). What it says names the keys that run a command in the key scheme you use, and yours where you rebound them: Home's reading shows the shelf's keys (C-k r f with standard keys, SPC r f with Vim keys) and changes when you switch, and so does "no PDF open".

Fenix asks it too

  • pdf.open: a PDF at a page or a heading -- gf on x.pdf#page=38, a standard's clause from the CCSDS toolkit.

  • pdf.search: a PDF searched -- the standards library's search.

What it may do

  • Run fenix-pdfium, which comes with Fenix. It reads the PDFs you open.

  • Know where you are in the editor: a project's own shelf, and links from it (yp).

Building

cargo xtask pack extensions/pdf dist

cargo test runs the reader against a fake fenix-pdfium and a fake Fenix (tests/reader.rs), checking what the pane shows pixel by pixel as you scroll, zoom and jump. Fenix's own tests drive the real program on a real PDF.
